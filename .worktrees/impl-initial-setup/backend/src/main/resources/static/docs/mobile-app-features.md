# Mobile App Features

## Login Screen
- **Description**: Allows users to log in using mock credentials.
- **Fields**: Email, Password.
- **Actions**: Submit login form.

## Activity Logging Screen
- **Description**: Allows users to log their workouts.
- **Fields**: Activity Type, Duration, Intensity.
- **Actions**: Submit activity form.

## Activity Retrieval Screen
- **Description**: Displays a list of logged activities.
- **Fields**: Activity List.
- **Actions**: View activity details.

## Real-Time Updates Screen
- **Description**: Displays real-time updates from workouts.
- **Fields**: Live Updates.
- **Actions**: View live updates.
